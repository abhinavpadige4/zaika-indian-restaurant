# Zaika Indian Restaurant

A responsive landing page for Zaika Indian restaurant built with React, Tailwind CSS, and Vite.

## Features

- Hero section with captivating background and call-to-action
- Responsive navbar with smooth scrolling
- About our master chefs section
- Testimonials carousel/slider
- Booking form with Formspree integration
- Footer with social media links
- Fully responsive design
- Smooth scrolling navigation
- Modern UI with gradients and animations

## Tech Stack

- React 18+
- Vite
- Tailwind CSS
- Framer Motion (for animations)
- React Router DOM (for navigation)
- Formspree (for form handling)
- GitHub Pages (for deployment)

## Sections

1. **Hero** - Landing section with restaurant branding and CTAs
2. **Navbar** - Responsive navigation with smooth scrolling
3. **About Chefs** - Meet the culinary team
4. **Testimonials** - Customer reviews and ratings
5. **Booking** - Table reservation form
6. **Menu** - Food menu showcase
7. **Footer** - Contact info and social links

## Deployment

This site is deployed via GitHub Pages at:
https://abhinavpadige4.github.io/zaika-indian-restaurant/

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Deploy to GitHub Pages
npm run deploy
```

## Smooth Scrolling

The navbar links use smooth scrolling to navigate to different sections of the page.

## Form Integration

The booking form uses Formspree for handling form submissions. Replace the form ID in `src/components/BookingContact.jsx` with your actual Formspree form ID.
